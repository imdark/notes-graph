macOS — "app can't be opened" / unsigned build

These canary builds aren't notarized yet, so Gatekeeper will grumble. After dragging NotesGraph to Applications, either right-click the app → Open → Open, or clear the quarantine flag in Terminal:

xattr -dr com.apple.quarantine /Applications/NotesGraph-canary.app
Android — sideloading the .apk

Open the downloaded file and, when prompted, allow your browser/file manager to install unknown apps. This is an unsigned canary build for testing, not a Play Store release.

Web Clipper — load the extension

Unzip the download, then open chrome://extensions in Chrome or Edge, enable Developer mode (top-right), click Load unpacked, and select the unzipped folder. Click the toolbar icon (or press ⌘/Ctrl+Shift+Y) on any page to clip it into your last workspace. Sign in to NotesGraph in the same browser first.

Is this really local-first?

Yes. Every doc is a node stored on your own drive; the AI construct runs on your own GPU. The cloud is optional — only used if you turn on sync. Source is on GitHub.
